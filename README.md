# 제철엔(N) - Seasonal Map

현재 시기와 사용자의 위치를 기반으로 제철 음식, 꽃, 행사, 장소를 지도 위에서 추천하는 웹 서비스입니다.

## 주요 기능

- 현재 위치 기반 제철 장소 지도
- 과일 / 수산물 / 꽃 / 행사 카테고리 필터
- 키워드 및 지역 검색
- 인기 제철 키워드 추천
- 저장한 장소 및 최근 본 장소 관리

## Tech Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: MySQL
- Map: Kakao Map API
- Place Data: Kakao Local API
- Trend Data: Naver DataLab Open API
- Deploy: Vercel, Render
